# Cryplex AI 项目介绍
Cryplex AI 是一个基于去中心化存储网络（DePIN）的区块链平台，专注于利用用户设备的闲置存储空间为人工智能（AI）训练提供高质量、安全的数据存储解决方案。

融资情况：800 万美元的种子轮融资，由 HuntX Labs 等机构支持。

该轮融资被描述为支持 Cryplex AI 提供加密项目发现和评级平台，涵盖 DeFi、NFT 和去中心化应用（dapps）等领域。

插件下载：https://chromewebstore.google.com/detail/cryplex-ai-storage-node/mpneoffefkhpfimnfmikkfgehgdahcdc

注册rf： https://app.cryplex.ai/dashboard?ref=bbuc1o
